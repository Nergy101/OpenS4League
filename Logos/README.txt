OpenS4League logo files
=======================

crest        full detail (hex lattice + trim keyline). Use at 64px and up.
crest-flat   no texture, no keyline. Use below 64px, and for favicons.
banner       1200x300, name + qualifier line.

-dark  = for dark backgrounds (ink #e7e5e4)
-light = for light backgrounds (ink #292524)

The 4 and the gap around the O are transparent cut-outs, so whatever sits
behind the logo shows through. Green is #5b7c32. Type is system-ui.
